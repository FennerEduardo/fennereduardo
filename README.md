## 🥒 Featured Open Source: [Gherkin AI](https://www.npmjs.com/package/gherkin-ai)

> **Engineering rails for AI agents** — Bridging the gap between business specifications and AI coding agents.

An **Enterprise-Grade Closed-Loop Agentic Orchestration Engine** published on npm that translates Gherkin `.feature` files into deterministic technical rails for AI agents (Claude Code, Cursor, Windsurf, Copilot).

```bash
npx gherkin-ai init
npx gherkin-ai generate --feature ./specs/auth.feature
npx gherkin-ai validate --feature ./specs/auth.feature
```

- **Deterministic by Design** — Agents receive explicit stack versions, strict TypeScript contracts, and Zod schemas instead of guessing.
- **Architecture-Aware** — Supports Hexagonal, DDD, Clean Architecture, CQRS, and Microservices.
- **Executable Specifications** — Generated test fixtures and `seed.sql` make scenarios actually runnable.

`TypeScript` `Node.js` `Zod` `Gherkin` `BDD` `AI Agents` `MCP`
